HOW TO EDIT:
1. Open config.js with Notepad or VS Code.
2. Replace primaryButtonUrl with the full HTTPS URL you own or are authorized to use.
3. Edit the text values in config.js. Do not delete the quotation marks or commas.
4. Save config.js.
5. Upload index.html, config.js and site.js to the SAME directory on your hosting.
6. Visit your hosted page and test the CTA button.

The original visual styles and embedded assets are preserved from your uploaded saved HTML.
The original backend and any external server-side features are NOT part of the saved HTML.
